Plush

A small, fast programming language with graphics and sound built in.

Install Plush __PLUSH_VERSION__

On macOS and Linux:

curl --proto '=https' -sSf https://maximecb.github.io/plush/install | sh

This installs into ~/.plush and puts plush on your PATH. Windows is not supported yet.

Try it

plush --run-example tremor

Or install and run a demo in one go:

curl --proto '=https' -sSf https://maximecb.github.io/plush/install | sh -s run-example tremor
